# @wts/frontend

SvelteKit dashboard — progress and pace charts, ETA, per-user contribution, timelapse.

**Deliberately empty.** The frontend is out of scope for v1 and returns as its own Wayfinder map
once v1 runs. A scaffolded-but-dead app is how deferred work leaks back in, so this stays a
placeholder rather than a skeleton.

v1 still *captures* everything this will need — the server-side tile store keeps the frames, and
the decay-ladder time series keeps the history. Only the rendering is deferred.

See the map: [#1](https://github.com/mia-riezebos/wplace-template-server/issues/1).
