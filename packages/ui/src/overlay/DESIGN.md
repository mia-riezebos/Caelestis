# Template artwork update

Reuse the existing overlay menu and button styles. Place the artwork action below appearance controls, where it remains separate from display settings. Use “Use canvas artwork” in both menus to keep the action readable within compact rows. Allow wrapping on narrow screens. Hover changes colour without changing control geometry. Disable the button during capture and save; show outcomes through existing notifications.

Server artwork actions require a usable token with verified admin access. Local updates need no token. Both entry points confirm the target change before capture, name the affected template, and explain that previous versions cannot currently be restored. Cancellation keeps the artwork unchanged.
