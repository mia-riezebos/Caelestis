# Coordination

Work belongs to the existing folder and template hierarchy. The frontend exposes a Work destination and scoped sections; the userscript opens Work from the existing tree menu. Painting controls stay compact.

Use the shared Caelestis theme tokens, system typeface, compact native controls, and aligned list rows. A selectable work list sits beside its details on wide screens and above them on narrow screens. Status, title, and painter identity carry the hierarchy. Tags and priority remain secondary.

Create and edit use one form. Claim and release are immediate actions. Assignment has an explicit username and numeric ID form. A stale edit keeps its draft and revision until the painter chooses Reload item. Activity retains each recorded revision and deleted link IDs.

Reuse folders and work-item tags for grouping. There are no campaign objects, milestone objects, or deadlines. Personal identity is temporarily self-reported; future authentication is tracked separately.

Preserve the host's light or dark theme. Native controls own keyboard interaction; the userscript's native dialog handles Escape and focus return. Add no animation for this workflow.
